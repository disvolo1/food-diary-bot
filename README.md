# 🍽 Food Diary Bot

Telegram-бот для ведения дневника питания.

## Возможности

- Настройка дневной нормы калорий
- Настройка белков, жиров и углеводов
- Распознавание пищевой ценности с фотографии
- Расчёт КБЖУ в зависимости от съеденного количества
- Учёт приёмов пищи
- Статистика за текущий день
- Расчёт оставшихся калорий и макронутриентов
- Удаление последнего приёма пищи

## Технологии

- Python
- aiogram 3
- Gemini API
- SQLite
- Railway
